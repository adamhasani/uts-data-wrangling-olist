# UTS Data Wrangling — Olist (Kelompok 5)

Notebook UTS Data Wrangling: pembersihan dan penyiapan dataset e-commerce Olist (orders + customers).

**Kelompok 5:** Muhammad Adam Hasani (25200013), Haidar Luthfi Kosasih (25200007), Virgio Arwa Sandhika (25200016) — Sains Data, Universitas Harkat Negeri.

## Cara menjalankan

1. Buka `Notebook_UTS_Data_Wrangling_Olist.ipynb` (mis. di Google Colab).
2. Run all. Selesai — data tidak perlu diunggah manual.

Notebook mencari data di folder `data_check/` di sampingnya. Bila folder itu tidak ada, `olist_orders.csv` dan `olist_customers.csv` diunduh otomatis dari repo ini.

## Isi repo

- `Notebook_UTS_Data_Wrangling_Olist.ipynb` — notebook utama (eksplorasi, cleaning, penggabungan, agregasi, validasi).
- `data_check/olist_orders.csv` — dataset mentah (tabel orders).
- `data_check/olist_customers.csv` — dataset tambahan (tabel customers).

## Sumber data

Dataset publik Olist Brazilian E-Commerce (Kaggle), data transaksi 2016–2018 yang sudah anonim.
